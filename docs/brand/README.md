# Mirattic mark

Main logo for Mirattic (account pages, docs, future landing). Same family as the app icons:
Sync = bare M, Flow = M + four-pane window + sparkle, **Mirattic = M + one round attic window**.

- Two ribbons meet in an M, the right one folding over the left (soft shadow at the seam).
- The space under the ribbons is the house (the "attic" in Mirattic); the round window sits in it.
- Gradient `#7C4DFF → #4F6BFF → #2FD3F5` (bottom-left → top-right), same as the app icons.

| file | use |
|---|---|
| `mirattic-mark.svg` | source, any size (also served as `/mark.svg` favicon by Auth) |
| `mirattic-mark-512.png` | app stores / social, transparent |
| `mirattic-mark-180.png` | apple-touch-icon |
| `mirattic-mark-32.png` | favicon fallback |

Below ~24 px the window disappears; the M alone still reads.
